# Progzt Aetheric

The official website for Progzt Aetheric. The site uses four focused static HTML pages
with a shared monochrome stylesheet. The search page uses DuckDuckGo's Instant Answer
API for summaries and related topics, with a link to full DuckDuckGo web results.

## Pages

- `index.html` — Home
- `founder.html` — Founder profile and organization journey
- `search.html` — DuckDuckGo Instant Answer search
- `contact.html` — Contact channels
