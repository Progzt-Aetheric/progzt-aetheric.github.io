# Progzt Aetheric

The official website for Progzt Aetheric. The site uses lightweight static HTML pages
with a shared monochrome stylesheet. The search page uses DuckDuckGo's Instant Answer
API for summaries and related topics, with a link to full DuckDuckGo web results.

## Pages

- `index.html` — Home
- `about.html` — Organization overview
- `work.html` — Areas of work
- `founder.html` — Founder
- `search.html` — DuckDuckGo Instant Answer search
- `status.html` — Platform status information
- `links.html` — Official links
- `contact.html` — Contact channels
